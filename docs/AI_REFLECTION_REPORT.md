# AI Usage Reflection Report

## How AI was Used
AI assistance was used to speed up implementation and documentation for this assignment under strict time constraints.

Main usage areas:
- Initial project scaffolding and folder planning
- Backend API boilerplate generation
- React page/component generation
- Route protection and auth flow setup
- Documentation drafting (API docs, architecture, schema, setup guide)

## Benefits
- Reduced development time significantly
- Improved consistency across backend and frontend
- Helped produce complete assignment deliverables in one workflow

## Human Decisions and Validation
I manually reviewed:
- Feature requirements from assignment brief
- Route structure and role permissions
- API request/response behavior
- Build and run commands

I also validated:
- Frontend production build (`npm run build`)
- Backend module loading (`node -e "require('./src/app')"`)

## Limitations and Improvements
- More extensive automated testing could improve confidence.
- Better error handling and form validation can be added in future.
- UI can be enhanced with richer dashboards/charts if required later.

## Conclusion
AI was used as a productivity accelerator, while final control remained with the developer for requirement mapping, validation, and final project structure.
